# 三鑫总公司工作系统（第一版框架）

这是一个响应式网页版工作台，入口为 `dist/index.html`，界面资源拆分为 `dist/ui.css` 和 `dist/app.js`。当前版本先在浏览器本地保存数据，适合整理真实资料和验证流程；接入多人共享前还需要部署数据库、登录和权限服务。

## 已搭建的框架

- 总公司总览：工厂、人员、货物库存、物料库存和数据健康度
- 工厂与仓库：组织、负责人、仓库数量和接入状态
- 人员管理：岗位、所属单位、联系方式和权限组
- 货物档案：统一编码、规格、类别、单位、安全库存
- 物料档案：原材料、辅料和设备工具等基础资料
- 库存流水：入库、出库、调拨、盘点和经办人追溯
- 真实录入：示例/真实模式切换、实体新增编辑停用、库存流水确认
- 数据工具：JSON 备份恢复、工厂/物品 CSV 导入、搜索筛选、低库存提醒
- 操作记录：记录档案、流水、导入和备份恢复动作
- 界面优化：当前模块搜索（Ctrl/Cmd + K）、低库存快捷登记、响应式间距、焦点态和可访问导航标记
- 总公司管理中心：组织资料入口、中文模块导航、移动端抽屉导航和预留模块说明
- 预留模块：采购、生产、财务、设备和项目

## 当前状态

`dist/core.js` 提供严格校验的数据层，`tests/core.test.cjs` 覆盖 13 组库存、确认顺序、停用状态、导入、备份和持久化测试。页面使用示例数据时会明确显示“示例数据”；切换真实模式后从空白状态开始。下一步接入多人共享时，可以增加登录、数据库、Excel 批量导入、角色权限和单据审批。

## 建议的数据主线

`工厂 → 仓库 → 物品档案 → 期初库存 → 入库/出库/调拨/盘点流水 → 当前库存`

每条流水保留单据编号、时间、仓库、物品、数量、经办人和审核状态，方便总公司查询和追溯。
